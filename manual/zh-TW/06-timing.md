# 判定時機與延遲調整

覺得「明明打準了卻總是出現 FAST 或 SLOW」「聲音聽起來有延遲」時，可以依本頁進行調整。
延遲程度因電腦、螢幕與音訊裝置而異，請依自己的環境進行調整。

依以下順序進行，比較容易調整到位：

1. 減少聲音的延遲
2. 減少畫面顯示的延遲
3. 調整判定時機

## 1. 減少聲音的延遲

在 設定 → **音訊** 中調整。變更後請按「套用」。

### 緩衝區大小

一次處理的音訊量。越小聲音延遲越少，但過小會導致聲音斷斷續續。
請將「緩衝區大小模式」設為「固定」，並在不斷音的範圍內選擇盡可能小的值。
建議從預設組合的 128 或 64 開始嘗試。

### Windows 的情況

在「後端」中選擇 WASAPI 後，可以變更「輸出模式」。

| 輸出模式 | 內容 |
| --- | --- |
| 共用 | 可以與其他應用程式同時發聲。延遲較大 |
| 共用低延遲 | 在與其他應用程式同時發聲的情況下減少延遲。適用於 Windows 10 以上 |
| 獨佔 | 只有 BMZ Player 發聲。延遲最低，但其他應用程式的聲音會停止 |

如果使用支援 ASIO 的音訊裝置，在「後端」中選擇 ASIO 可能進一步減少延遲。
使用 ASIO 時，裝置驅動程式一側的緩衝區設定可能優先。

## 2. 減少畫面顯示的延遲

在 設定 → **影像** 中調整。

| 項目 | 內容 |
| --- | --- |
| 同步模式 | 選擇是否防止畫面撕裂。防止時顯示會略微延遲 |
| 畫格延遲 | 設為「低延遲」可減少顯示延遲。畫面卡頓時請設為「穩定」 |
| 目標 FPS | 每秒繪製次數的上限。設為 0 時不設上限 |
| 視窗模式 | 全螢幕可能減少顯示延遲 |

## 3. 調整判定時機

### 自動判定調整（推薦）

遊玩中按 **0** 鍵即可開啟自動判定調整。
維持開啟玩幾首歌後，顯示偏移（下一項）會依你的擊打時機逐步調整。
調整合適後，請再按一次 **0** 關閉。

### 顯示偏移

將音符看起來抵達判定線的時機相對於聲音前後移動。
在 設定 → **遊玩** 的「判定」中變更「顯示偏移」。遊玩中也可以用 **3** / **9** 鍵以 1 毫秒為單位變更。

- **FAST** 較多時，往負方向調整。
- **SLOW** 較多時，往正方向調整。

想依視覺調整擊打時機時，使用此項。

### 輸入偏移

將按鍵或按鈕的判定時機相對於聲音前後移動。
用於控制器等輸入裝置本身有延遲的情況。
SLOW 較多時往正方向調整，FAST 較多時往負方向調整。

通常只調整顯示偏移就足夠了。如果兩者都大幅變更，會難以判斷問題出在哪一邊，請注意。

## FAST / SLOW 顯示

擊打過早時顯示 FAST，過晚時顯示 SLOW。
將 設定 → **遊玩** 的「FAST/SLOW 顯示模式」設為「閾值 (ms)」後，PGREAT 時也能顯示 FAST / SLOW。
在「FAST/SLOW 顯示閾值」中指定 PGREAT 偏差多少時顯示。設為 0 時所有判定都會顯示。
