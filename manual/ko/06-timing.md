# 판정 타이밍과 지연 조정

'제대로 쳤는데 FAST나 SLOW만 나온다', '소리가 늦게 들린다'고 느낄 때의 조정 방법입니다.
컴퓨터나 모니터, 오디오 기기에 따라 늦어지는 정도가 다르므로 환경에 맞춰 조정합니다.

다음 순서로 진행하면 맞추기 쉽습니다.

1. 소리의 지연 줄이기
2. 화면 표시의 지연 줄이기
3. 판정 타이밍 맞추기

## 1. 소리의 지연 줄이기

설정 → **오디오**에서 조정합니다. 바꾼 뒤에는 '적용'을 누르세요.

### 버퍼 크기

소리를 한꺼번에 처리하는 양입니다. 작게 할수록 소리의 지연이 줄지만, 너무 작으면 소리가 뚝뚝 끊깁니다.
'버퍼 크기 모드'를 '고정'으로 하고, 끊기지 않는 범위에서 가능한 한 작은 값을 고르세요.
프리셋의 128이나 64부터 시험해 보기를 추천합니다.

### Windows의 경우

'백엔드'에서 WASAPI를 고르면 '출력 모드'를 바꿀 수 있습니다.

| 출력 모드 | 내용 |
| --- | --- |
| 공유 | 다른 앱과 동시에 소리를 낼 수 있습니다. 지연은 큰 편입니다 |
| 공유 저지연 | 다른 앱과 동시에 소리를 내면서 지연을 줄입니다. Windows 10 이상에서 쓸 수 있습니다 |
| 단독 | BMZ Player만 소리를 냅니다. 지연을 가장 작게 할 수 있지만 다른 앱의 소리는 멈춥니다 |

ASIO를 지원하는 오디오 기기를 쓴다면 '백엔드'에서 ASIO를 고르면 지연을 더 줄일 수 있습니다.
ASIO에서는 기기 드라이버 쪽의 버퍼 설정이 우선될 수 있습니다.

## 2. 화면 표시의 지연 줄이기

설정 → **영상**에서 조정합니다.

| 항목 | 내용 |
| --- | --- |
| 동기화 모드 | 화면 찢어짐(티어링)을 막을지 고릅니다. 막는 설정으로 하면 표시가 조금 늦어집니다 |
| 프레임 지연 | '낮은 지연'으로 하면 표시 지연이 줄어듭니다. 끊겨 보이면 '안정'으로 하세요 |
| 목표 FPS | 1초 동안 그리는 횟수의 상한입니다. 0이면 상한이 없습니다 |
| 창 모드 | 전체 화면으로 하면 표시 지연이 줄 수 있습니다 |

## 3. 판정 타이밍 맞추기

### 자동 판정 조정(추천)

플레이 중에 **0** 키를 누르면 자동 판정 조정이 켜집니다.
켠 채로 몇 곡 플레이하면, 치는 타이밍에 맞춰 표시 오프셋(다음 항목)이 조금씩 조정됩니다.
알맞게 되면 다시 **0**을 눌러 끄세요.

### 표시 오프셋

노트가 판정선에 닿아 보이는 타이밍을 소리에 대해 앞뒤로 옮깁니다.
설정 → **플레이**의 '판정'에 있는 '표시 오프셋'에서 바꿉니다. 플레이 중에도 **3** / **9** 키로 1ms씩 바꿀 수 있습니다.

- **FAST**가 많이 나오면 - 방향으로 조정합니다.
- **SLOW**가 많이 나오면 + 방향으로 조정합니다.

눈으로 보고 치는 타이밍을 맞추고 싶을 때 이것을 씁니다.

### 입력 오프셋

키나 버튼을 눌렀을 때의 판정을 소리에 대해 앞뒤로 옮깁니다.
컨트롤러 등 입력 기기 자체가 늦을 때 씁니다.
SLOW가 많이 나오면 + 방향, FAST가 많이 나오면 - 방향으로 조정합니다.

보통은 표시 오프셋만으로 충분합니다. 둘 다 크게 바꾸면 어느 쪽이 원인인지 알기 어려워지므로 주의하세요.

## FAST / SLOW 표시

너무 빨리 쳤을 때는 FAST, 너무 늦게 쳤을 때는 SLOW가 표시됩니다.
설정 → **플레이**의 'FAST/SLOW 표시 모드'를 '임계값 (ms)'으로 하면 PGREAT일 때도 FAST / SLOW를 표시할 수 있습니다.
'FAST/SLOW 표시 임계값'에서 PGREAT 중 얼마나 어긋나면 표시할지 지정합니다. 0으로 하면 모든 판정에서 표시합니다.
