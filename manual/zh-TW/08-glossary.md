# 用語集

本頁說明 BMS 與本手冊中使用的用語。

## 遊玩用語

| 用語 | 意義 |
| --- | --- |
| BMS | 由玩家製作並公開的音樂遊戲譜面資料格式。也用來指歌曲本身 |
| BMSON | BMS 的一種較新的格式 |
| PMS | 用 9 個按鈕遊玩的譜面格式 |
| 差分 | 由歌曲作者以外的人製作的追加譜面。放入原歌曲的資料夾中使用 |
| 難度表 | 玩家們將 BMS 譜面依難度排列的列表 |
| 段位 | 連續遊玩指定歌曲以認定實力的課程 |
| 面板 | 畫面設計。可以為選曲畫面、遊玩畫面等分別選擇 |
| IR | 網路排名（Internet Ranking）的縮寫。可以線上比較成績 |
| SP / DP | 使用單側按鍵遊玩的單打，與使用兩側按鍵遊玩的雙打 |
| 5K / 7K / 10K / 14K / 9K | 按鍵數。10K 為兩側各 5 鍵，14K 為兩側各 7 鍵。9K 即 PMS |
| 轉盤 | 位於按鍵旁、透過轉動操作的轉盤。鍵盤上指派給 Shift 與 Ctrl |

## 判定與成績用語

| 用語 | 意義 |
| --- | --- |
| PGREAT / GREAT / GOOD / BAD / POOR | 判定。PGREAT 最好，POOR 為失誤 |
| 空 POOR | 在沒有音符的地方按下時的 POOR |
| FAST / SLOW | 表示擊打時機過早還是過晚 |
| EX SCORE | 以 PGREAT 記 2 分、GREAT 記 1 分計算的分數 |
| BP | BAD 與 POOR 的合計數。可作為失誤數的參考 |
| 連擊 | 連續取得 GOOD 以上判定的次數 |
| 全連 | 保持連擊直到歌曲結束 |
| 評級 | 依分數比例決定的評價（AAA、AA、A 等） |
| 過關燈 | 每個譜面最好的過關狀況。在選曲畫面中以顏色區分顯示 |
| 失敗（FAILED） | HARD 等血條歸零，歌曲中途結束 |

## 選項用語

| 用語 | 意義 |
| --- | --- |
| 流速 | 音符落下的速度 |
| 綠色數字 | 表示音符從出現在畫面上到抵達判定線所需時間的數字。越小看起來越快 |
| SUDDEN+ / HIDDEN+ / LIFT | 遮住軌道上方的遮罩、遮住下方的遮罩，以及抬高判定線的功能 |
| LN | 長條音符（Long Note）的縮寫。指需要持續按住的音符 |
| CN / HCN | 放開時機也會被判定的長條音符。HCN 按住期間血條也會增減 |
| GAS | 血條自動切換（Gauge Auto Shift）的縮寫。失敗後切換到其他血條繼續遊玩 |
| 偏移 | 修正聲音、顯示、判定時機偏差的數值 |
| 重播 | 記錄遊玩操作的資料。之後可以播放，或作為對戰對手 |
| 個人檔案 | 設定與成績的集合。多人共用一台電腦時等情況下可以分開使用 |

各選項的詳細說明請參閱[遊玩選項](05-play-options.md)。
