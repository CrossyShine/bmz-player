# Glossary

Terms used in BMS and in this manual.

## Playing

| Term | Meaning |
| --- | --- |
| BMS | A chart format for rhythm games, made and published by the community. Also used to mean the songs themselves |
| BMSON | A newer BMS-style format |
| PMS | Charts played with 9 buttons |
| Sabun | An extra chart made by someone other than the song's creator. Put it in the original song's folder |
| Difficulty table | A community-made list of BMS charts sorted by difficulty |
| Dan (class) course | A course of set songs played in a row to certify your skill |
| Skin | The screen design. You can choose one for each screen, such as song select and play |
| IR | Internet ranking. Lets you compare scores online |
| SP / DP | Single play with one side of keys, and double play with both sides |
| 5K / 7K / 10K / 14K / 9K | The number of keys. 10K is 5 keys on both sides and 14K is 7 keys on both sides. 9K is PMS |
| Turntable (scratch) | The disc next to the keys that you spin. On a keyboard it is bound to Shift and Ctrl |

## Judgements and scores

| Term | Meaning |
| --- | --- |
| PGREAT / GREAT / GOOD / BAD / POOR | Judgements. PGREAT is the best, and POOR is a miss |
| Empty POOR | A POOR from pressing when there is no note |
| FAST / SLOW | Shows whether you hit too early or too late |
| EX SCORE | A score that counts 2 points per PGREAT and 1 point per GREAT |
| BP | The total number of BADs and POORs. A rough count of your misses |
| Combo | The number of GOOD or better judgements in a row |
| Full combo | Keeping the combo to the end of the song |
| Rank | A grade based on your score percentage (AAA, AA, A, and so on) |
| Clear lamp | Your best clear result for each chart. Shown by color on the song select screen |
| Fail | When a gauge such as HARD reaches 0 and the song ends early |

## Options

| Term | Meaning |
| --- | --- |
| Hi-speed | How fast notes fall |
| Green number | A number for how long a note takes to reach the judgement line. Smaller looks faster |
| SUDDEN+ / HIDDEN+ / LIFT | A cover that hides the top of the lane, a cover that hides the bottom, and a setting that raises the judgement line |
| LN | Long note. A note you hold down |
| CN / HCN | Long notes whose release is also judged. With HCN, the gauge also changes while you hold |
| GAS | Gauge auto shift. Keeps you playing on a lower gauge after you fail a higher one |
| Offset | A value that corrects timing differences between sound, display, and input |
| Replay | A recording of your inputs in a play. You can watch it later or play against it |
| Profile | A set of settings and scores. Useful when several people share one computer |

See [Play options](05-play-options.md) for details about each option.
