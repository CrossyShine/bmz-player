# 判定时机与延迟调整

觉得“明明打准了却总是出现 FAST 或 SLOW”“声音听起来有延迟”时，可以按本页进行调整。
延迟程度因电脑、显示器和音频设备而异，请根据自己的环境进行调整。

按以下顺序进行，更容易调整到位：

1. 减少声音的延迟
2. 减少画面显示的延迟
3. 调整判定时机

## 1. 减少声音的延迟

在 设置 → **音频** 中调整。更改后请按“应用”。

### 缓冲区大小

一次处理的音频量。越小声音延迟越少，但过小会导致声音断断续续。
请将“缓冲区大小模式”设为“固定”，并在不断音的范围内选择尽可能小的值。
建议从预设的 128 或 64 开始尝试。

### Windows 的情况

在“后端”中选择 WASAPI 后，可以更改“输出模式”。

| 输出模式 | 内容 |
| --- | --- |
| 共享 | 可以与其他应用同时发声。延迟较大 |
| 共享低延迟 | 在与其他应用同时发声的情况下减少延迟。适用于 Windows 10 及以上 |
| 独占 | 只有 BMZ Player 发声。延迟最低，但其他应用的声音会停止 |

如果使用支持 ASIO 的音频设备，在“后端”中选择 ASIO 可能进一步减少延迟。
使用 ASIO 时，设备驱动程序一侧的缓冲区设置可能优先。

## 2. 减少画面显示的延迟

在 设置 → **视频** 中调整。

| 项目 | 内容 |
| --- | --- |
| 同步模式 | 选择是否防止画面撕裂。防止时显示会略微延迟 |
| 帧延迟 | 设为“低延迟”可减少显示延迟。画面卡顿时请设为“稳定” |
| 目标 FPS | 每秒绘制次数的上限。设为 0 时不设上限 |
| 窗口模式 | 全屏可能减少显示延迟 |

## 3. 调整判定时机

### 自动判定调整（推荐）

游玩中按 **0** 键即可开启自动判定调整。
保持开启玩几首歌后，显示偏移（下一项）会根据你的击打时机逐步调整。
调整合适后，请再按一次 **0** 关闭。

### 显示偏移

将音符看起来抵达判定线的时机相对于声音前后移动。
在 设置 → **游玩** 的“判定”中更改“显示偏移”。游玩中也可以用 **3** / **9** 键以 1 毫秒为单位更改。

- **FAST** 较多时，向负方向调整。
- **SLOW** 较多时，向正方向调整。

想根据视觉调整击打时机时，使用此项。

### 输入偏移

将按键或按钮的判定时机相对于声音前后移动。
用于控制器等输入设备本身存在延迟的情况。
SLOW 较多时向正方向调整，FAST 较多时向负方向调整。

通常只调整显示偏移就足够了。如果两者都大幅更改，会难以判断问题出在哪一边，请注意。

## FAST / SLOW 显示

击打过早时显示 FAST，过晚时显示 SLOW。
将 设置 → **游玩** 的“FAST/SLOW 显示模式”设为“阈值 (ms)”后，PGREAT 时也能显示 FAST / SLOW。
在“FAST/SLOW 显示阈值”中指定 PGREAT 偏差多少时显示。设为 0 时所有判定都会显示。
