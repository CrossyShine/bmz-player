# 용어집

BMS와 이 매뉴얼에서 쓰는 말의 뜻입니다.

## 플레이 관련 용어

| 용어 | 뜻 |
| --- | --- |
| BMS | 사용자들이 만들어 공개하는 리듬 게임용 채보 데이터 형식입니다. 곡 자체를 가리키기도 합니다 |
| BMSON | BMS의 새로운 형식 중 하나입니다 |
| PMS | 9개의 버튼으로 플레이하는 형식의 채보입니다 |
| 차분 | 곡의 작자가 아닌 사람이 만든 추가 채보입니다. 원래 곡의 폴더에 넣어 씁니다 |
| 난이도표 | 사용자들이 BMS 채보를 난이도 순으로 정리한 목록입니다 |
| 단위 | 정해진 곡을 이어서 플레이해 실력을 인정받는 코스입니다 |
| 스킨 | 화면 디자인입니다. 선곡 화면·플레이 화면 등마다 고를 수 있습니다 |
| IR | 인터넷 랭킹의 약자입니다. 점수를 온라인으로 비교할 수 있습니다 |
| SP / DP | 한쪽 건반으로 플레이하는 싱글 플레이와 양쪽 건반으로 플레이하는 더블 플레이입니다 |
| 5K / 7K / 10K / 14K / 9K | 건반 수입니다. 10K는 5키 양쪽, 14K는 7키 양쪽으로 플레이합니다. 9K는 PMS입니다 |
| 스크래치 | 건반 옆에 있는, 돌려서 조작하는 턴테이블입니다. 키보드에서는 Shift와 Ctrl에 할당되어 있습니다 |

## 판정과 점수 관련 용어

| 용어 | 뜻 |
| --- | --- |
| PGREAT / GREAT / GOOD / BAD / POOR | 판정입니다. PGREAT가 가장 좋고, POOR는 미스입니다 |
| 공 POOR | 노트가 없는 곳에서 눌렀을 때의 POOR입니다 |
| FAST / SLOW | 친 타이밍이 너무 빨랐는지 너무 늦었는지를 나타냅니다 |
| EX SCORE | PGREAT를 2점, GREAT를 1점으로 센 점수입니다 |
| BP | BAD와 POOR의 합계 수입니다. 미스 수의 기준이 됩니다 |
| 콤보 | GOOD 이상을 연속으로 받은 수입니다 |
| 풀 콤보 | 곡 끝까지 콤보를 이어 가는 것입니다 |
| 랭크 | 점수 비율로 정해지는 평가입니다(AAA, AA, A 등) |
| 클리어 램프 | 채보마다의 최고 클리어 상황입니다. 선곡 화면에 색으로 구분해 표시됩니다 |
| 폐점 | HARD 등의 게이지가 0이 되어 곡 도중에 종료하는 것입니다 |

## 옵션 관련 용어

| 용어 | 뜻 |
| --- | --- |
| 하이스피드 | 노트가 떨어지는 속도입니다 |
| 녹색 숫자 | 노트가 화면에 나타나서 판정선에 닿기까지의 시간을 나타내는 숫자입니다. 작을수록 빠르게 보입니다 |
| SUDDEN+ / HIDDEN+ / LIFT | 레인 위쪽을 가리는 커버, 아래쪽을 가리는 커버, 판정선을 올리는 기능입니다 |
| LN | 롱노트의 약자입니다. 계속 누르는 노트를 가리킵니다 |
| CN / HCN | 떼는 타이밍도 판정되는 롱노트입니다. HCN은 누르고 있는 동안에도 게이지가 오르내립니다 |
| GAS | 게이지 오토 시프트의 약자입니다. 폐점해도 다른 게이지로 바꿔 계속 플레이합니다 |
| 오프셋 | 소리·표시·판정 타이밍의 어긋남을 보정하는 값입니다 |
| 리플레이 | 플레이 조작을 기록한 것입니다. 나중에 재생하거나 대전 상대로 삼을 수 있습니다 |
| 프로필 | 설정과 점수의 묶음입니다. 한 대의 컴퓨터를 여러 사람이 쓸 때 등에 나눌 수 있습니다 |

각 옵션의 자세한 설명은 [플레이 옵션](05-play-options.md)을 참고하세요.
