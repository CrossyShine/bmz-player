# 用語集

BMS やこのマニュアルで使う言葉の意味です。

## 遊び方の用語

| 用語 | 意味 |
| --- | --- |
| BMS | 有志が作って公開している音楽ゲーム用の譜面データの形式です。曲そのものを指して使うこともあります |
| BMSON | BMS の新しい形式の 1 つです |
| PMS | 9 つのボタンで遊ぶ形式の譜面です |
| 差分 | 曲の作者以外の人が作った追加譜面です。元の曲のフォルダに入れて使います |
| 難易度表 | 有志が BMS の譜面を難しさ順に並べた一覧です。「発狂 BMS 難易度表」などがあります |
| 段位 | 決められた曲を続けて遊び、実力を認定するコースです |
| スキン | 画面のデザインです。選曲画面・プレイ画面などごとに選べます |
| IR | インターネットランキングの略です。スコアをオンラインで比べられます |
| SP / DP | 片側の鍵盤で遊ぶシングルプレイと、両側の鍵盤で遊ぶダブルプレイです |
| 5K / 7K / 10K / 14K / 9K | 鍵盤の数です。10K は 5 鍵の両側、14K は 7 鍵の両側で遊びます。9K は PMS です |
| スクラッチ | 鍵盤の横にある、回して操作するターンテーブルです。キーボードでは Shift と Ctrl に割り当てられています |

## 判定とスコアの用語

| 用語 | 意味 |
| --- | --- |
| PGREAT / GREAT / GOOD / BAD / POOR | 判定です。PGREAT が最もよく、POOR はミスです |
| 空 POOR | ノーツがないところで押したときの POOR です |
| FAST / SLOW | 叩いたタイミングが早すぎたか、遅すぎたかを表します |
| EX SCORE | PGREAT を 2 点、GREAT を 1 点として数えたスコアです |
| BP | BAD と POOR の合計数です。ミスの数の目安になります |
| コンボ | 続けて GOOD 以上を取った数です |
| フルコンボ | 曲の最後までコンボを続けることです |
| ランク | スコアの割合で決まる評価です（AAA、AA、A など） |
| クリアランプ | 譜面ごとの最高のクリア状況です。選曲画面で色分けして表示されます |
| 閉店 | HARD などのゲージが 0 になり、曲の途中で終了することです |

## オプションの用語

| 用語 | 意味 |
| --- | --- |
| ハイスピード | ノーツが降ってくる速さです |
| 緑数字 | ノーツが画面に現れてから判定ラインに届くまでの時間を表す数字です。小さいほど速く見えます |
| SUDDEN+ / HIDDEN+ / LIFT | レーンの上側を隠すカバー、下側を隠すカバー、判定ラインを持ち上げる機能です |
| LN | ロングノートの略です。押し続けるノーツを指します |
| CN / HCN | 離すタイミングも判定されるロングノートです。HCN は押している間もゲージが増減します |
| GAS | ゲージオートシフトの略です。閉店しても下のゲージに切り替えて遊び続けます |
| オフセット | 音・表示・判定のタイミングのずれを補正する値です |
| リプレイ | プレイの操作を記録したものです。あとから再生したり、対戦相手にしたりできます |
| プロファイル | 設定とスコアのまとまりです。1 台のパソコンを複数人で使うときなどに分けられます |

各オプションの詳しい説明は[プレイオプション](05-play-options.md)を参照してください。
