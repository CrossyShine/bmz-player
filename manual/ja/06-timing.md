# 判定タイミングと遅延の調整

「ちゃんと叩いているのに FAST や SLOW ばかり出る」「音が遅れて聞こえる」と感じたときの調整方法です。
パソコンやモニター、オーディオ機器によって遅れ方が違うため、環境に合わせて調整します。

次の順に進めると、うまく合わせやすくなります。

1. 音の遅れを減らす
2. 画面表示の遅れを減らす
3. 判定タイミングを合わせる

## 1. 音の遅れを減らす

設定 → **音声** で調整します。変更したら「適用」を押してください。

### バッファサイズ

音声をまとめて処理する量です。小さくするほど音の遅れが減りますが、小さすぎると音がプツプツ途切れます。
「バッファサイズモード」を「固定」にし、途切れない範囲でできるだけ小さい値を選んでください。
プリセットの 128 や 64 から試すのがおすすめです。

### Windows の場合

「バックエンド」で WASAPI を選ぶと、「出力モード」を変えられます。

| 出力モード | 内容 |
| --- | --- |
| 共有 | ほかのアプリと同時に音を出せます。遅れは大きめです |
| 共有 低遅延 | ほかのアプリと同時に音を出しながら、遅れを減らします。Windows 10 以降で使えます |
| 排他 | BMZ Player だけが音を出します。遅れを最も小さくできますが、ほかのアプリの音は止まります |

ASIO に対応したオーディオ機器を使っている場合は、「バックエンド」で ASIO を選ぶとさらに遅れを減らせることがあります。
ASIO では、機器のドライバー側のバッファ設定が優先される場合があります。

## 2. 画面表示の遅れを減らす

設定 → **映像** で調整します。

| 項目 | 内容 |
| --- | --- |
| 同期モード | 画面のちらつき（ティアリング）を防ぐかどうかを選びます。防ぐ設定にすると、表示がわずかに遅れます |
| フレーム遅延 | 「低遅延」にすると表示の遅れが減ります。カクつく場合は「安定」にしてください |
| 目標 FPS | 1 秒間に描画する回数の上限です。0 にすると上限なしになります |
| ウィンドウモード | フルスクリーンにすると、表示の遅れが減ることがあります |

## 3. 判定タイミングを合わせる

### 自動判定調整（おすすめ）

プレイ中に **0** キーを押すと、自動判定調整が ON になります。
ON のまま何曲か遊ぶと、あなたの叩くタイミングに合わせて表示オフセット（次の項目）が少しずつ調整されます。
ちょうどよくなったら、もう一度 **0** を押して OFF にしてください。

### 表示オフセット

ノーツが判定ラインに届いて見えるタイミングを、音に対して前後にずらします。
設定 → **プレイ** の「判定」にある「表示オフセット」で変更します。プレイ中も **3** / **9** キーで 1 ms ずつ変えられます。

- **FAST** が多く出るときは、マイナス方向に調整します。
- **SLOW** が多く出るときは、プラス方向に調整します。

目で見て叩くタイミングを合わせたい場合は、こちらを使います。

### 入力オフセット

キーやボタンを押したときの判定を、音に対して前後にずらします。
コントローラーなどの入力機器そのものが遅れている場合に使います。
SLOW が多く出るときはプラス方向、FAST が多く出るときはマイナス方向に調整します。

通常は表示オフセットだけで十分です。両方を大きく変えると、どちらが原因かわからなくなるので注意してください。

## FAST / SLOW の表示

判定が早すぎたときは FAST、遅すぎたときは SLOW と表示されます。
設定 → **プレイ** の「FAST/SLOW 表示モード」を「閾値 (ms)」にすると、PGREAT のときも FAST / SLOW を表示できます。
「FAST/SLOW 表示閾値」で、PGREAT のうちどれだけずれたら表示するかを指定します。0 にすると、すべての判定で表示します。
