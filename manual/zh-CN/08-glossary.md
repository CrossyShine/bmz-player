# 用语集

本页说明 BMS 和本手册中使用的用语。

## 游玩用语

| 用语 | 含义 |
| --- | --- |
| BMS | 由玩家制作并公开的音乐游戏谱面数据格式。也用来指歌曲本身 |
| BMSON | BMS 的一种较新的格式 |
| PMS | 用 9 个按钮游玩的谱面格式 |
| 差分 | 由歌曲作者以外的人制作的追加谱面。放入原歌曲的文件夹中使用 |
| 难度表 | 玩家们将 BMS 谱面按难度排列的列表 |
| 段位 | 连续游玩指定歌曲以认定实力的课程 |
| 皮肤 | 画面设计。可以为选曲画面、游玩画面等分别选择 |
| IR | 网络排名（Internet Ranking）的缩写。可以在线比较成绩 |
| SP / DP | 使用一侧按键游玩的单人游玩，和使用两侧按键游玩的双人游玩 |
| 5K / 7K / 10K / 14K / 9K | 按键数。10K 为两侧各 5 键，14K 为两侧各 7 键。9K 即 PMS |
| 转盘 | 位于按键旁、通过转动操作的转盘。键盘上分配给 Shift 和 Ctrl |

## 判定与成绩用语

| 用语 | 含义 |
| --- | --- |
| PGREAT / GREAT / GOOD / BAD / POOR | 判定。PGREAT 最好，POOR 为失误 |
| 空 POOR | 在没有音符的地方按下时的 POOR |
| FAST / SLOW | 表示击打时机过早还是过晚 |
| EX SCORE | 以 PGREAT 记 2 分、GREAT 记 1 分计算的分数 |
| BP | BAD 与 POOR 的合计数。可作为失误数的参考 |
| 连击 | 连续取得 GOOD 以上判定的次数 |
| 全连 | 保持连击直到歌曲结束 |
| 评级 | 按分数比例决定的评价（AAA、AA、A 等） |
| 通关灯 | 每个谱面最好的通关状况。在选曲画面中以颜色区分显示 |
| 失败（FAILED） | HARD 等血条归零，歌曲中途结束 |

## 选项用语

| 用语 | 含义 |
| --- | --- |
| 流速 | 音符落下的速度 |
| 绿色数字 | 表示音符从出现在画面上到抵达判定线所需时间的数字。越小看起来越快 |
| SUDDEN+ / HIDDEN+ / LIFT | 遮住轨道上方的遮罩、遮住下方的遮罩，以及抬高判定线的功能 |
| LN | 长条音符（Long Note）的缩写。指需要持续按住的音符 |
| CN / HCN | 松开时机也会被判定的长条音符。HCN 按住期间血条也会增减 |
| GAS | 血条自动切换（Gauge Auto Shift）的缩写。失败后切换到其他血条继续游玩 |
| 偏移 | 修正声音、显示、判定时机偏差的数值 |
| 回放 | 记录游玩操作的数据。之后可以播放，或作为对战对手 |
| 配置档案 | 设置和成绩的集合。多人共用一台电脑时等情况下可以分开使用 |

各选项的详细说明请参阅[游玩选项](05-play-options.md)。
